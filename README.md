# Pak Arab Manpower Supply LLC

Premium, responsive corporate website for Pak Arab Manpower Supply LLC, Abu Dhabi.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is generated in `dist/`.

## Included

- Mobile-first responsive layout
- GSAP + ScrollTrigger motion
- Performance-aware Vanta.js background with reduced-motion and mobile fallbacks
- Generated and optimized original campaign imagery
- Lucide icon system
- WhatsApp enquiry flow
- SEO and social metadata
